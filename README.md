# Progress — Ozon Bank frontend test task

Прототип переиспользуемого блока `Progress` на чистом HTML/CSS/JavaScript без сторонних библиотек и фреймворков.

## Реализовано

- `Normal`: значение `0–100` управляет размером дуги от 12 часов по часовой стрелке.
- `Animated`: независимая бесконечная анимация вращения по часовой стрелке.
- `Hidden`: скрытие блока со страницы.
- API компонента: `setValue`, `setAnimated`, `setHidden`, `getValue`, `getState`, `destroy`.
- Валидация пользовательского ввода и ограничение значения диапазоном `0–100`.
- Адаптация под portrait / landscape и мобильные экраны.
- `prefers-reduced-motion` для пользователей с ограничением анимации.
- SVG используется для точного и производительного отображения окружности без canvas/redraw.
